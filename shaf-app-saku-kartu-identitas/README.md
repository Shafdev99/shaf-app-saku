# Paket spesifikasi Kartu Identitas shaf-app-saku

Isi paket:
- `PRD.md`: PRD lengkap yang diselaraskan dengan fitur kartu identitas.
- `AGENT.md`: instruksi kerja Codex yang diperbarui.
- `PROMPT-CODEX.md`: instruksi ringkas siap-tempel ke Codex.
- `template-kartu/`: tiga gambar template yang diberikan pengguna.

Paket ini berisi dokumen dan template saja, bukan source code aplikasi yang telah diubah. Archive proyek yang diperiksa mengandung `.env` dan `.git`; karena alasan keamanan, archive itu tidak disalin ke paket ini. Implementasi aktual harus dilakukan di working tree proyek yang benar oleh Codex, lalu diuji.
